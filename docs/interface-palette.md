# ARTWIN interface palette

Reviewed the [official ARTWIN homepage](https://artwin.kg/) on 15 September 2026. Its consultation button and several accents use `#ffd008`; primary text is black / `#121212`, dark panels use `#1f1f1f`, and surfaces are white / `#fafafa`. This is an interface interpretation of the public website, not an official brand manual.

`src/theme.css` owns the shared interface colors. Project browsing, the finder, apartment controls, dialogs, comparison, presentation, sales workspace, loading illustration and planning sketch use these tokens.

- Use yellow with dark text for primary actions and selected filters. Hover states use a slightly darker yellow.
- Use charcoal with white text for dark panels, and neutral gray for secondary text, borders and surfaces.
- Use pale yellow for highlights. Small text on a light surface must stay dark; the yellow accent is not a text color.
- Use a dark gold focus ring so keyboard focus is visible on both white and yellow.
- Preserve the recognized green WhatsApp contact button and semantic warning/error states. Do not tint project photographs, floor-plan reference images or 3D furnishing materials to match the interface.

There is no pricing, availability or project-content change associated with this palette update.
